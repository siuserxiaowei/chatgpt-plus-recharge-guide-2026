## 不默认购买更贵的套餐

先判断目前的工作是否真的受限，再比较升级能否解决具体问题。

| 情况 | 下一步 |
|---|---|
| 日常改写和问答可以完成 | 继续现有套餐，记录偶发限制 |
| 文件或复杂任务反复中断 | 核对对应工具与用量，再考虑 Plus |
| 已有 Plus，长期受限 | 记录用量瓶颈，对照当前 Pro 条件 |
| 主要是 API 调用 | 单独评估 API 账单 |
| 已付款但没有权益 | 查单和排查，不追加购买 |

档位标签不能直接推导所有模型和工具的次数。已有订阅能否升级、是否可续费、当前是否接受新购，都要核对。
